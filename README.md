## 📌 Project Overview

The **Hospital Data Analysis** project uses PostgreSQL and SQL queries to explore hospital records, analyze patient-related data, and extract meaningful insights from structured healthcare data.

The project demonstrates practical SQL skills, data exploration, filtering, aggregation, and database querying for data analytics.

## 🎯 Project Objectives

- Analyze hospital records using SQL.
- Retrieve relevant information through structured queries.
- Apply aggregate functions to summarize data.
- Identify useful patterns and insights in healthcare data.
- Strengthen practical PostgreSQL and database management skills.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| PostgreSQL | Database management and SQL analysis |
| pgAdmin 4 | Database interface and query execution |
| SQL | Data querying and analysis |

## 🔍 SQL Concepts Covered

- `SELECT` and `WHERE` — Data retrieval and filtering
- `ORDER BY` — Sorting query results
- `GROUP BY` — Grouping records for analysis
- Aggregate Functions — Summarizing data
- Filtering Conditions — Extracting relevant records

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open pgAdmin 4 and connect to PostgreSQL.
3. Create or select the appropriate database.
4. Import or execute the SQL script.
5. Run the queries and review the results.

## 📈 Key Learnings

- Writing and executing SQL queries in PostgreSQL.
- Working with structured healthcare datasets.
- Applying filtering, sorting, and aggregation techniques.
- Developing a practical approach to data analysis.
