# 🏥 Hospital Data Analysis Using PostgreSQL

## 📌 Project Overview
This project focuses on analyzing hospital data using PostgreSQL to extract meaningful insights through SQL queries.

## 🎯 Objectives
- Analyze hospital patient data.
- Perform data filtering, sorting, and aggregation.
- Extract useful insights using SQL queries.
- Improve data analysis and database management skills.

## 🛠️ Tools & Technologies
- PostgreSQL
- pgAdmin 4
- SQL

## 📂 Dataset
The project uses hospital data containing 100 records for SQL-based analysis.

## 🔍 Key SQL Concepts
- SELECT and WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- Data Filtering and Analysis

## 🚀 How to Use
1. Download the SQL file from this repository.
2. Open PostgreSQL using pgAdmin 4.
3. Execute the SQL queries.
4. Explore the results to understand the analysis.

## 📈 Key Learnings
- Practical experience with PostgreSQL.
- Writing and executing SQL queries.
- Analyzing structured hospital data.
- Extracting insights from datasets.
